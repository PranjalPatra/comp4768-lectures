Functions

Learning outcomes

By the end of this lecture, you should be able to:

  • define and call functions with typed parameters and return values;
  • choose positional, optional positional, and named parameters;
  • use anonymous and arrow functions as values and arguments;
  • create objects with fields, methods, getters, setters, and constructors.

A function gives a name to a reusable block of code. Its declaration states the return type, function name, parameters, and body.

int add(int a, int b) {
  return a + b;
}

void main() {
  var result = add(7, 5);
  print(result);
}
12

Return Values and Void

A function that produces a value declares its return type. A function that performs an action without producing a value uses void.

String planetLabel(String name) {
  return 'Planet: $name';
}

void showLabel(String label) {
  print(label);
}

void main() {
  var label = planetLabel('Mars');
  showLabel(label);
}
Planet: Mars

Function Tracing

int nextYear(int year) {
  return year + 1;
}

void main() {
  var year = 2026;
  print(nextYear(year));
  print(year);
}
Question

What two values are printed? Does the call change the variable year in main()?

Answer

The program prints 2027 and then 2026. The parameter receives the current integer value. Returning year + 1 does not assign a new value to the caller's variable.

Required Positional Parameters

Required positional arguments are matched to parameters by position.

String describePlanet(String name, int moons) {
  return '$name has $moons moon(s).';
}

void main() {
  print(describePlanet('Mars', 2));
}
Mars has 2 moon(s).

Optional Positional Parameters

Square brackets make positional parameters optional. A default value is used when an argument is omitted.

String greet(String name, [String greeting = 'Hello']) {
  return '$greeting, $name!';
}

void main() {
  print(greet('Alice'));
  print(greet('Bob', 'Hi'));
}
Hello, Alice!
Hi, Bob!

Named Parameters

Curly braces declare named parameters. A call supplies each argument with parameterName: value.

void createUser({
  required String name,
  int age = 18,
  String? email,
}) {
  print('$name, $age, $email');
}

void main() {
  createUser(name: 'Alice', age: 25);
  createUser(name: 'Bob');
  createUser(age: 30, name: 'Charlie');
}
Alice, 25, null
Bob, 18, null
Charlie, 30, null

String? means the value may be null. Null is the subject of the next lecture.

Question

Which of these calls compile: createUser(age: 20), createUser('Alice'), and createUser(name: 'Al', 25)?

Answer

None compile. The first omits required name. The second supplies a positional argument to a function with only named parameters. The third also supplies the required name incorrectly because 25 is an extra positional argument.

Functions as Values

An anonymous function is a function without a declared name. It can be stored in a variable and called through that variable.

void main() {
  var sayHello = (String name) {
    return 'Hello, $name!';
  };

  print(sayHello('Dart'));
}
Hello, Dart!

Functions as Arguments

An operation can receive a function and call it for each value. Such a received function is a callback.

void main() {
  var names = ['alice', 'bob', 'charlie'];
  var upperCaseNames = names.map((name) {
    return name.toUpperCase();
  }).toList();

  print(upperCaseNames);
}
[ALICE, BOB, CHARLIE]

Arrow Functions

Arrow syntax writes a function whose body is one expression. The expression's value is returned automatically.

var multiply = (int a, int b) => a * b;
var doubled = [1, 2, 3].map((n) => n * 2).toList();

void main() {
  print(multiply(5, 3));
  print(doubled);
}
15
[2, 4, 6]
Question

Rewrite aListOfStrings.any((s) { return s.isEmpty; }) with arrow syntax.

Answer

aListOfStrings.any((s) => s.isEmpty). The expression s.isEmpty becomes the returned value for each callback call.

Class Structure

A class describes a kind of object. It can declare fields, constructors, and methods.

class Spacecraft {
  String name;
  DateTime? launchDate;

  Spacecraft(this.name, this.launchDate);

  void describe() {
    print('Spacecraft: $name');
  }
}

Creating Objects

Calling a constructor creates an object and returns a reference to it.

class Spacecraft {
  String name;
  DateTime? launchDate;

  Spacecraft(this.name, this.launchDate);
}

void main() {
  var voyager = Spacecraft('Voyager I', DateTime(1977, 9, 5));
  var futureMission = Spacecraft('Europa Clipper', null);
  print(voyager.name);
  print(futureMission.launchDate);
}
Voyager I
null

Fields and Methods

Methods can read and change the fields of the object on which they are called.

class Counter {
  int value = 0;

  void increment() {
    value += 1;
  }
}

void main() {
  var counter = Counter();
  counter.increment();
  counter.increment();
  print(counter.value);
}
2

Getters and Setters

A getter reads a value like a property. A setter handles an assignment to a property. A leading _ makes a member private to its file.

import 'dart:math';

class Square {
  double side;
  Square(this.side);

  double get area => side * side;

  set area(double value) {
    side = sqrt(value);
  }
}
class MyClass {
  int value1 = 2;
  int value2 = 3;
  int value3 = 5;

  int get product => value1 * value2 * value3;
  void incrementValue1() => value1++;
}
Question

Does square.area call the getter or the setter? Which one runs for square.area = 25?

Answer

Reading square.area calls the getter. Assigning to square.area calls the setter with 25 as its argument.

Generative Constructors

A generative constructor creates a new instance and initializes its fields. Parameters beginning with this. assign directly to fields of the same name.

class MyColor {
  int red;
  int green;
  int blue;

  MyColor(this.red, this.green, this.blue);
}

These are alternative named-parameter forms for the constructor:

MyColor({required this.red, required this.green, required this.blue});

// Or, with defaults:
MyColor({this.red = 0, this.green = 0, this.blue = 0});

required is explained in the next lecture.

Question

For each constructor form shown, which calls compile: MyColor(80, 80, 128), MyColor(red: 80, green: 80, blue: 128), and MyColor(red: 80)?

Answer

The positional form accepts only the first call. The required named form accepts only the second. The defaulted named form accepts the second and third calls. Treat the constructor declarations as alternatives, since a class cannot declare all three as unnamed constructors at once.

Named Constructors

A named constructor gives a class another clearly named way to create an object.

class Point {
  final double x;
  final double y;

  Point(this.x, this.y);
  Point.origin() : x = 0, y = 0;
}

void main() {
  var position = Point(3, 4);
  var origin = Point.origin();

  print('${position.x}, ${position.y}');
  print('${origin.x}, ${origin.y}');
}
3.0, 4.0
0.0, 0.0

Default Constructors

If a class declares no constructor, Dart supplies an unnamed constructor with no arguments.

class Point {
  double x = 0;
  double y = 0;
}

void main() {
  var point = Point();
  print('${point.x}, ${point.y}');
}
0.0, 0.0

Non-nullable fields must still receive values before construction completes.

AI Explanation

Functions

The return type int appears before the name add. It promises that a completed call produces an integer. The parameters int a and int b introduce local names for the arguments supplied by the caller.

Execution begins in main(). The call add(7, 5) assigns 7 to a and 5 to b for this call. The function evaluates a + b, returns 12, and the assignment stores that value in result.

The parameter is the name in the declaration. The argument is the value at the call site. Function declarations such as add normally appear outside main().

Return Values and Void

planetLabel creates and returns a string. Its call can therefore appear on the right side of an assignment. showLabel prints its argument and returns no value that the program uses.

The declared return type lets Dart check every returned value. Returning an integer from planetLabel would be a type error because the declaration promises a String.

Function Tracing

The name year is used in two different scopes. The local variable in main() belongs to main. The parameter named year belongs to nextYear and receives the value 2026 for the call.

The expression year + 1 creates the returned value 2027. No assignment changes the variable in main(), so the second print still reads 2026.

Required Positional Parameters

The first argument supplies name, and the second supplies moons. Both are required, so omitting either argument is an error.

Position carries meaning in this form. Reversing the arguments would fail here because 2 is not a String and 'Mars' is not an int. When several arguments have the same type, reversing them may compile but still produce the wrong meaning.

Optional Positional Parameters

name remains required. The parameter greeting is inside square brackets, so the caller may stop after the first argument. In that case, greeting receives 'Hello'.

The second call supplies a value for the optional position, replacing the default for that call. Optional positional parameters must come after the required positional parameters.

Named Parameters

The braces do not make every parameter optional. The required modifier means that a call must name name. The optional parameter age receives 18 when omitted, and the optional nullable parameter email receives null when omitted.

Named arguments can appear in any order. The third valid call writes age first even though name appears first in the declaration. Dart matches by name rather than position.

Functions as Values

The expression beginning with (String name) creates a function value. The assignment stores that value in sayHello. Parentheses after the variable name call the stored function.

Anonymous functions are also called lambdas or closures. They are useful when a short piece of behavior is needed locally or passed to another operation.

A function type can state the parameter types and return type explicitly. For example, int Function(int, int) operation = add; stores a function that receives two integers and returns an integer. The assignment stores the function itself because there are no call parentheses after add.

Functions as Arguments

map takes one list element at a time and passes it to the anonymous function. That function returns an uppercase string. map produces those returned values in the same order, and toList() collects them into a list.

An operation that receives or returns a function is called a higher-order function. The callback gives map the specific transformation to perform.

Arrow Functions

The syntax => expression is equivalent to a block containing return expression;. It is suitable only when the function body is a single expression.

Arrow syntax changes the form, not the meaning. Use a block when the function needs several statements or when the steps are clearer when written separately.

Class Structure

The fields name and launchDate store data for each object. The constructor has the same name as the class and initializes those fields. The method describe defines behavior available on each Spacecraft object.

DateTime? allows the launch date to be absent. Each object gets its own field values.

Creating Objects

The first call creates an object whose two fields receive the supplied values. The second creates a different object and uses null for its nullable launch date.

The dot reads a member of an object. voyager.name and futureMission.launchDate refer to fields in different objects even though both objects share the same class definition.

Fields and Methods

Because Counter declares no constructor, Dart supplies a default no-argument constructor. The field initializer sets value to zero before the object is used.

Each call to increment runs with counter as the current object and adds one to that object's field. A second Counter() object would have a separate value starting at zero.

Getters and Setters

The getter has no call parentheses at the use site. It calculates an area from the current side length. The setter receives the assigned area and changes side so the square has that area.

Both product and incrementValue1 use arrow syntax because each body contains one expression. The expression after => is returned by the getter. The void method performs the increment and does not return a value for the caller to use.

The source used a rectangle whose area setter changed both dimensions. This square version preserves a clear relationship between the stored side and computed area. The sqrt function comes from dart:math.

The underscore privacy rule applies at the library level. In this single-file example, saying private to its file is the useful first approximation. Libraries and imports are introduced when the course begins multi-file Flutter projects.

Generative Constructors

The positional constructor requires three arguments in order. The first named form requires all three names but allows them in any order. The defaulted named form allows any of the three arguments to be omitted.

An initializing formal such as this.red replaces a separate assignment from a parameter to the field. The two declarations in the second block show alternative forms for the same class and are not meant to appear together.

Named Constructors

Both constructors create a Point. The unnamed constructor Point(this.x, this.y) receives coordinates from the caller. The named constructor Point.origin() communicates that both coordinates will be zero.

The period between Point and origin is part of the constructor's name. The colon introduces field initialization that happens before the constructor body. Initializer lists are covered with the other constructor forms in L5.

A subclass does not inherit a superclass's named constructors. If a subclass needs its own origin constructor, it must declare that constructor itself.

Default Constructors

The implicit constructor works because both fields have initializers. Removing those initializers would leave the non-nullable fields without values, so the class declaration would be rejected.

Declaring any constructor removes the automatically supplied one. A class with only Point(this.x, this.y) cannot also be called as Point() unless a separate no-argument constructor is declared.
