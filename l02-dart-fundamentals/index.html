Learning outcomes

By the end of this lecture, you should be able to:

  • trace assignments and distinguish var, final, const, and late;
  • read basic Dart types and string interpolation;
  • choose a list, set, or map for a small data problem;
  • trace collection access and simple updates;
  • trace branches and loops, including their boundary cases.

Dart is a programming language developed by Google for applications across platforms. It is the language used by Flutter.

  • Static type checking checks whether values are used with suitable types.
  • Just-in-Time (JIT) compilation compiles code while a program runs.
  • Ahead-of-Time (AOT) compilation compiles code before a program runs.
  • Garbage collection manages memory that a program no longer needs.

Strings and Interpolation

String interpolation inserts a value into text. Use $name for a variable and ${expression} for a calculation or other expression.

var name = 'Voyager';
var year = 1977;
print('$name launched in $year');
print("The following year was ${year + 1}");
Voyager launched in 1977
The following year was 1978

Single and double quotes both create strings.

Variables and Assignment

With var, Dart infers the type from the initial value. Omitting the written type does not remove type checking.

var name = 'John'; // Inferred type: String
name = 'Jane';    // Allowed
print(name);
Jane

This separate fragment has a type error:

var name = 'John';
name = 42; // Error: an int cannot be assigned to String.

Final Variables

A final variable can be assigned once. Its value may be determined at runtime, while the program is running.

final name = 'John';
print(name);
final now = DateTime.now();
John

Adding name = 'Jane'; would be an error. DateTime.now() obtains the current date and time, so now is determined when this code runs.

Compile-Time Constants

A const variable has a value that can be determined at compile time, before execution. It cannot be reassigned.

const pi = 3.14;
const radius = 5;
const area = pi * radius * radius;
print(area);
78.5

This declaration is rejected:

const now = DateTime.now(); // Error: not a constant expression.

Late Initialization

late allows a declaration whose initialization will be checked at runtime. The value must be assigned before it is read.

late String description;

void main() {
  description = 'A small planet';
  print(description);
}
A small planet

String here is non-nullable: it cannot hold null, the value representing absence. late does not supply a string or make the type nullable.

Lists and Mutability

A mutable list is a list whose contents can change. Making its variable final prevents reassignment of the variable, but still allows changes to this list.

final planets = <String>['Earth', 'Mars'];
planets.add('Venus');
print(planets);
[Earth, Mars, Venus]

Maps

A map associates a key with a value. Each key identifies at most one entry.

var distances = {'Earth': 1.0, 'Mars': 1.52};

The keys are planet names; the values are numeric distances. Assigning an existing key replaces its value. Assigning a new key adds an entry.

If-Else Statements

Control flow determines which statements run and how often. An if chain selects the first branch whose Boolean condition is true.

var year = 1977;
if (year >= 2001) {
  print('21st century');
} else if (year >= 1901) {
  print('20th century');
} else {
  print('Before 20th century');
}
20th century

For Loops

A loop repeats a body of code. This for loop has initialization, a condition, and an update.

for (var i = 0; i < 3; i++) {
  print(i);
}
0
1
2

Initialize i once. Before each repetition, test i < 3. After the body, i++ increases i by one. When i reaches 3, the condition is false.

Iterating Through Collections

A for-in loop takes one element at a time. Use an indexed for loop when the position is also needed.

var planets = ['Earth', 'Mars'];
for (var planet in planets) {
  print(planet);
}
for (var i = 0; i < planets.length; i++) {
  print('$i: ${planets[i]}');
}
Earth
Mars
0: Earth
1: Mars

While Loops

A while loop tests its condition before each repetition. If the first test is false, its body never runs.

var year = 2023;
while (year < 2025) {
  year += 1;
  print(year);
}
2024
2025

year += 1 adds one and assigns the result back to year. The body must make progress toward ending the loop.

Do-While Loops

A do-while loop runs its body before testing its condition, so the body runs at least once.

var year = 2000;
do {
  year -= 1;
  print(year);
} while (year > 2000);
1999
Question

Starting from year = 2000, how many times does each version run its body: while (year > 2000) and do ... while (year > 2000)?

Answer

The while body runs zero times because its first test is false. The do-while body runs once, subtracts one, and prints 1999; its first test is then false.

Switch-Case Statements

A switch statement selects a case by value; default handles anything unmatched.

var planet = 'Mars';
switch (planet) {
  case 'Earth':
    print('Our home');
    break;
  case 'Mars':
    print('The red planet');
    break;
  default:
    print('Another planet');
}
The red planet
Question

What is printed for 'Venus', and would 'Earth' also execute the default branch?

Answer

'Venus' prints Another planet. 'Earth' prints only Our home; execution leaves the switch after its matching case.

Transforming Lists

A callback is a function passed to another operation. In (p) => p.toUpperCase(), p is a parameter, a name receiving a value when the function is called. => gives the expression returned by that function. map applies it to each element; toList() collects the resulting sequence into a list.

var planets = ['Mars', 'Earth'];
var uppercased = planets.map((p) => p.toUpperCase()).toList();
var sortedPlanets = [...planets]..sort();
var firstOne = planets.sublist(0, 1);
print(uppercased);
print(sortedPlanets);
print(firstOne);
print(planets);
[MARS, EARTH]
[Earth, Mars]
[Mars]
[Mars, Earth]

...planets spreads the elements into a new list. The cascade ..sort() calls sort() on that new list and keeps the list as the expression's result. sort() modifies its receiver in place; here the receiver is the copy. The original list remains in its original order. sublist also creates a new list for the selected range.

Alternative List Iteration

planets.asMap().forEach((index, planet) =>
  print('Planet $index: $planet'));

Map Iteration

The keys form an iterable, a sequence that for-in can traverse. Entries let the body read both parts directly. Map forEach supplies the key and value as arguments to its callback.

var planets = {'Earth': 1.0, 'Mars': 1.52};
for (var key in planets.keys) {
  print('$key: ${planets[key]}');
}
planets.forEach((key, value) => print('$key: $value'));
for (var entry in planets.entries) {
  print('${entry.key}: ${entry.value}');
}
Earth: 1.0
Mars: 1.52
Earth: 1.0
Mars: 1.52
Earth: 1.0
Mars: 1.52

All three forms visit the same entries. The first looks up each value by key; the other two provide the value along with the key.

Overview of Dart

Dart provides a standard library of commonly needed operations and tools for developing programs. It supports web and mobile development. Flutter supplies the user-interface toolkit; the examples here use Dart alone.

Dart is object-oriented: classes describe kinds of objects, and single inheritance allows a class to extend one superclass. These are background features here, not prerequisites for tracing the examples. The core task is to follow values through a small program.

A declaration may omit a written type annotation. Dart still checks types when it infers them from values.

Hello World

The text 'Hello, World!' is the argument supplied to print: an argument is a value passed in a function call. print is a top-level function, so this call does not need an object before its name.

The semicolon ends the statement. With two print statements, execution reaches the first, prints one line, and then reaches the second and prints another.

In the remaining slides, code blocks are fragments to place inside main(), unless a complete main() is shown. Each fragment starts fresh; variables do not carry over from one slide to the next. Lines labelled as errors illustrate rejected or failing code.

Basic Types

A declaration introduces a variable. In int year = 1977;, int is the type, year is the name, and 1977 is the initial value. An assignment such as distance = 42.5; changes an existing variable's value.

Basic Type Reference

Both int and double are subtypes of num: a variable declared as num can hold either kind of number. A floating-point number represents a numeric value with a fractional part, subject to the representation's precision.

The words true and false are Boolean values, not strings. Quoting 'true' would make text instead.

Strings and Interpolation

The first print substitutes the current values of name and year. The second evaluates year + 1, then inserts the result. It does not assign that result back to year, which remains 1977.

An expression is code that produces a value. The braces after $ mark the whole expression to evaluate. They are needed here because the insertion includes addition, not just a variable name.

Variables and Assignment

Type inference means that Dart determines a type without requiring you to write it. The first declaration has the same relevant type constraint as String name = 'John';.

Changing the string value does not change the variable's type. The second fragment is rejected because 42 is an integer, not a string. Use var for local variables when the initial value makes the type clear.

Final Variables

The first assignment fixes which value name holds. A second assignment is rejected even if it supplies another string of the correct type.

“Assigned once” describes the variable. It does not mean every object held by a final variable is unchangeable. We will examine that distinction with a list.

The date and time are not printed here because the exact value changes from run to run. Use final when you do not intend to replace a variable's value after initialization.

Compile-Time Constants

Every value in the calculation of area is already constant. The calculation therefore meets the compile-time requirement.

The current time is available only at runtime, so it can initialize a final variable but cannot initialize a const variable. Both prevent reassignment; const adds the requirement that the initial value be a constant expression. Fixed numeric values or configuration values are common uses.

Late Initialization

This complete program declares description outside main, at the top level. When main runs, it assigns a string and then reads it. Removing the assignment leaves the runtime check with no initialized value, so the read fails.

late is useful when initialization must happen after declaration. It can also support lazy initialization, where an initializer is evaluated when the value is first used. It is not required for every local variable declared before its assignment; Dart can sometimes establish that an ordinary local variable is assigned before use. It can also reject a definitely unassigned local late variable before execution; the shown top-level declaration demonstrates the runtime check.

The declaration choices answer different questions: var asks Dart to infer a type, final prevents reassignment, const requires a compile-time constant, and late moves initialization checking to runtime.

Creating Lists

An element is one value in a collection. The repeated 'Earth' is kept because lists do not require uniqueness.

The initial values let Dart infer List<String> for planets. The explicit declaration for moons gives the same kind of element constraint. With an empty list, writing the element type states what may be added even though there are no initial values to infer it from.

The ordinary list literals used here create growable lists, so their size can change. Lists are suitable for an ordered sequence, especially when positions or repeated values matter.

Indexing

The first read selects the third element. The assignment replaces the first element without changing the list's length. first and last then read the elements at the two ends.

Index Range

An empty list has no valid element index. Reading first or last also requires a nonempty list. A position outside the list does not produce an extra element; the access fails.

Adding and Removing Elements

After add, the list is ['Earth', 'Mars', 'Earth', 'Venus']. Removing the first occurrence of 'Earth' leaves the other occurrence in place. There are then three elements, with new indexes 0, 1, and 2.

A method is an operation called on a value, such as planets.add(...). The dot connects the value to the operation. A property such as length is read without call parentheses.

List Information

isEmpty asks whether the list has zero elements. contains asks whether at least one element matches the supplied value. Neither operation changes the list.

The result -1 is a missing-value signal from indexOf, not a valid list index. It must not be used as though it identified the last element.

Lists and Mutability

There are two separate things to track: the variable and the object it holds. The variable continues to refer to the same list after add. The list's contents and length have changed.

This distinction is why “final means nothing can change” is too broad. For these list literals, final fixes the variable's assignment, not the contents of the list.

Sets

Adding 'Helium' a second time leaves the set with two elements. Use a list if those two occurrences need to be represented separately.

A set models membership rather than numbered positions. The literal sets used here do retain insertion order when iterated, but they still have no elements[0] operation.

The study reference includes set union, intersection, and difference, which combine or compare membership.

Maps

The initial map has two entries. Adding 'Jupiter' increases that count to three. Updating 'Earth' changes its value without creating a second Earth entry.

Dart infers Map<String, double> from these initial keys and values. The two type positions describe different roles, unlike the single element type in List<String> or Set<String>.

Map Lookup

There is no Mars entry, so the lookup reports absence with null. That is different from a list access beyond its bounds, which fails.

Even though the stored values in distances are doubles, lookup must also allow for a missing key. This is the reason a lookup is not automatically a usable numeric value. Here we print it directly; no additional null-handling syntax is needed.

The empty map declaration states that keys will be strings and values will be integers. The reference sheet includes access to all keys, values, and entries.

Choosing a Collection

The same subject can need different collections. An observation record must preserve repeated observations and their sequence, so a list fits. A set answers which planets appeared without counting repeats. A map answers a different question: what distance is associated with a particular name?

Choose by the data's meaning and the operations needed, rather than by which brackets look familiar.

If-Else Statements

>= means “greater than or equal to”. The first comparison is false for 1977, so execution proceeds to the second comparison. That comparison is true, so its body runs. The final else is skipped.

Only one branch runs. For 2001, both comparisons would be true if evaluated independently, but the first branch is selected and the later ones are skipped. The final else handles values that fail both conditions.

For Loops

A repetition is also called an iteration. The order is initialization, test, body, update, then back to the test. The update does not happen before the first body execution.

The loop prints three values, even though the last printed value is two. Starting at zero and stopping before three is the same boundary pattern used by a three-element list's valid indexes.

Iterating Through Collections

The first loop assigns each successive element to planet and executes the body. It does not require you to maintain an index. A set can also be traversed with for-in.

The second loop uses i both as a printed position and as an index. Its strict < comparison matters: an index equal to planets.length would be outside the list.

Map traversal uses keys or entries, rather than list indexes. The study reference shows those forms and the source's forEach alternatives.

While Loops

At the first test, 2023 < 2025 is true. The body increments the year before printing, so the first printed value is 2024. The next body execution prints 2025. Only then does the next test fail.

If year started at 2025, the loop would print nothing. If the update were removed while year remained below 2025, the condition would never become false and the loop would continue.

Do-While Loops

year -= 1 subtracts one and assigns the result back. The first action in the shown loop is this subtraction, not the comparison. By the time year > 2000 is evaluated, year is already 1999.

The placement of the condition changes the minimum number of executions. Use that placement as the first step when tracing either form.
